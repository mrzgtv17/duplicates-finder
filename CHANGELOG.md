# История изменений

Каждый раздел «## X.Y.Z» становится описанием релиза на GitHub и показывается
в программе в окне «Доступно обновление».

## 1.3.2

- Исправлено: на Windows после автообновления программа не запускалась с ошибкой
  «Can't find a usable init.tcl». Новая версия теперь стартует как отдельная программа.
  Обновление на 1.3.2 ещё может один раз показать эту ошибку (её вызывает старая версия) —
  просто закройте окна и запустите программу снова.

## 1.3.1

- Обновлены компоненты автоматической сборки на GitHub (поддержка новых версий GitHub Actions).
  В самой программе изменений нет.

## 1.3.0

- Программа для Mac (.app) и Windows (.exe) собирается автоматически на GitHub.
- Обновление прямо из программы: меню «Обновления → Проверить обновления…».
- Проверка обновлений при запуске (можно отключить в меню «Обновления»).

## 1.2.0

- Удаление лишних копий в Корзину прямо из таблицы.
- «Оставить только выбранный» — удалить все остальные копии файла.
- Защита: нельзя удалить все копии одного файла.

## 1.1.0

- Поиск дубликатов на Яндекс Диске через API, без скачивания файлов.
- Окно программы вместо командной строки.

## 1.0.0

- Поиск дубликатов в папке или на диске, отчёт для Excel с полными адресами файлов.
